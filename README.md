# 你好，我是坚冰（MinosIE）

坐标上海 · 全栈工程师，前端为主战场 · 2014 年入坑 GitHub · [在线简历](https://minosie.github.io/MinosIE/)

一个需求从界面到落库到上线，我可以一个人闭环。偏爱小而完整的工具：能在本机跑完的就不上云，能零依赖的就不引框架。

**后端** · Node.js（Express / Fastify）· MySQL · Redis · TypeORM · JWT · 云环境 COS

**跨端 & 桌面** · 微信小程序（Taro / uni-app）· 微信云函数 · Tauri
